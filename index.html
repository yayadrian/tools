Tools

Small, single-purpose utilities. Web tools open in the browser; CLI tools link to their source on GitHub.

  • 🎯 Central Circle Web Click a spot on the map to draw concentric distance rings around it.
  • 🎄 Christmas Timer Web Work backwards from serving time so every dish lands on the table together.
  • 🔌 EV Charging Comparer Web Compare home, destination and rapid chargers by price, speed and your car's real limits.
  • 🏃 GitHub Projects Sprints CLI Create sprint iterations in GitHub Projects v2 from a CSV file.
  • ⛽ Hybrid Petrol Calculator Web Estimate petrol and electric running costs per mile for a plug-in hybrid.
  • 🧹 Jellyfin Watched Cleaner CLI Delete already-watched videos from a Jellyfin library, dry-run by default.
  • 🍞 Bread Nutrition Calculator Web Calories, protein and fibre per loaf and per slice for a bread recipe.
  • 🌤️ parkrun Weather Advisor Web Check the forecast for your next parkrun and get told what to wear.
  • 🕓 Quarters of the Year Web A clock-style view of the four quarters with progress through the current one.
  • 🍚 Rice Cooking Calculator Web Get the right water-to-rice ratio for fluffy or softer basmati on an induction hob.
  • 🏋️ Treadmill Blackout Web Track a speed x incline grid and black out squares as you complete sessions.
  • 📷 Webcam Image Viewer Web Keep a set of still-image webcams in one page and refresh them together.
  • 🎥 Webcam Tiles Web Arrange one or more HLS webcam streams into tiles and watch them side by side.
  • 🗺️ Workflow to GPX CLI Convert JSON location tracks into GPX files you can open in mapping apps.
  • 🗓️ Working Hours Calculator Web Design and compare two-week working patterns, saved in your browser.
  • 📺 YouTube Age Search Web Search YouTube and only show videos older than a minimum age.
  • 🎵 YouTube Playlist to Music CLI Download playlists or videos as M4A audio with metadata and cover art.
Source on GitHub. Add a tool by creating a folder and describing it in tools.json.
