A4 Mini Notebook Folding Guide

Make an 8-page mini notebook from one sheet of A4. Type or add images to each page if you like (hover a page for the + image button, or drag/paste an image in — it all saves automatically), then print at 100% scale, A4 landscape and follow the dashed fold lines and the single red cut. The top row prints upside-down on purpose so it reads the right way once folded. The numbered steps below show how.

How to fold

Print at 100% scale (no "fit to page"). The cut is a single short slit in the very middle of the sheet — it lets the folded paper open into a cross so it can collapse into a booklet.
